# DevOps TaskBoard — Python + FastAPI + Docker + GitHub Actions

Учебное приложение для мастер-класса DevOps. Репозиторий будет содержать фронтенд, REST API, тесты, Docker Compose и CI/CD.

После загрузки файлов локальный запуск: `cp .env.example .env`, установите `DB_PASSWORD`, затем `docker compose up -d --build --wait`.

Автоматическая выкладка на сервер отключена по умолчанию до настройки SSH и GitHub Variables.
